[백테스팅 기능 명세서]

- 백테스팅은 일반 주식, 배당 주식 두가지로 분류 (일드맥스가 아닌 모든 주는 일반주로 분류)
- 가상의 투자자를 설정하고 원금 설정 후 투자자의 포트폴리오 설정 가능
- 가상 투자자 여러명이 가능하며 각각 로컬스토리지에 데이터 저장
- 일반 주식의 경우 포트폴리오 설정만 가능
- 배당 주식의 경우 4가지 종류의 배당 정책 설정 가능
  - 배당 정책 1: 배당금의 n%를 배당주에 재투자 (원활한 계산을 위해 최대 2뎁스까지만 가능)
  - 배당 정책 2: 배당금의 n%를 일반주에 재투자 (포트폴리오 설정)
  - 배당 정책 3: 배당금 재투자하지 않음
